# Logo Novarion

Simpan file logo resmi angkatan di folder ini:
`apps/web/public/logo.png`

### Ketentuan File:
1. **Format:** PNG transparan (recommended)
2. **Nama file yang didukung otomatis:**
   - `logo.png` (sangat direkomendasikan)
   - `logo.PNG`
   - `novarion-logo.png`
   - atau di dalam subfolder: `apps/web/public/images/logo.png`
3. **Ukuran yang ideal:**
   - Resolusi tinggi (misal: lebar 300px - 800px, tinggi proporsional).
   - Tinggi akan disesuaikan otomatis oleh navbar (`max-h-10` / 40px) dan proporsinya tetap terjaga (`object-contain`).

Website dan navbar/header akan langsung memuat dan menampilkan logo ini secara otomatis!
