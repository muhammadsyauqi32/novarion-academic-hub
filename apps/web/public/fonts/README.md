# Novarion Custom Fonts

Folder ini disiapkan untuk font kustom **Enrika**.

### Cara Penggunaan:
1. Taruh file font Enrika Anda di folder ini:
   `apps/web/public/fonts/`
2. Nama file yang didukung otomatis:
   - `enrika.woff2` (sangat direkomendasikan untuk web)
   - `enrika.otf`
   - `enrika.ttf`
   - `Enrika.otf`
   - `Enrika.ttf`
   - `Enrika.woff2`
   - `enrika-bold.woff2` / `enrika-bold.otf` / `enrika-bold.ttf` (opsional untuk versi tebal)

Aplikasi sudah dikonfigurasi untuk memuat font ini secara otomatis sebagai `font-heading` dan class `font-enrika`.
